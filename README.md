## Files

- `script.js` — mobile navigation

## Publish with GitHub Pages (free)
1. Sign in to GitHub: https://github.com/
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace with your actual GitHub username).
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root folder.
4. Open the repository's **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. Your site should be available at `https://YOUR-GITHUB-USERNAME.github.io/`.
